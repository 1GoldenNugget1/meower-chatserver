# MEOWER - TCP CHAT SERVER WRITTEN IN GO 

 Meower is simple chat server that you are able  host on any machine with Golang installed.

 currently supported commands:

 **/help** - display help menu <br>
 **/nick [new name]** - change your chat name<br>
 **/exit** - gracefully disconnect from the server<br>

feel free to make a PR with your own commands that you think
could make it better.

**CURRENTLY SERVER IS UNENCRYPTED MY NEXT MILESTONE IS TO MAKE IT SSL ENCRYPTED**

to  connect to the running server:

1. download ncat/netcat  for your platform of choice
2. run ncat/nc [server ip] 2190
3. choose your nickname and happy meowing!
